# 교원 채용공고 알리미 · Android 0.1.3

서울교육일자리포털·경기도교육청·동경한국학교와 추가한 게시판에서 **제목에 ‘역사’가 들어 있는 공고만** 모아보는 개인용 앱입니다.

## 0.1.3 아이콘 적용

사용자가 승인한 갈색 배경·흰색 말풍선·갈색 학교 시안 PNG를 다시 그리거나 변형하지 않고 앱 아이콘으로 적용했습니다. 원본 파일을 그대로 리소스에 복사했고 Android가 표시 크기에 맞춰 렌더링합니다.

원본 SHA-256: `ce7cdcd7cf5f973cc32359f46e3f168e34e36afbd8062b6d75693da64b22f0b1`

앱 이름과 흰색·연회색·갈색 테마, 제목 기준 수집 기능은 동일합니다.

## 0.1.2 화면 변경

- 앱스 화면 이름과 앱 상단 제목을 ‘교원 채용공고 알리미’로 통일했습니다.
- 상단 지역 안내와 영문 소제목을 정리했습니다.
- 흰색 배경, 연회색 경계와 가벼운 그림자, 갈색(#7B533E) 포인트를 적용했습니다.
- 색상 선택 기능은 추가하지 않았습니다.
- 이 버전에서는 아이콘을 검토용으로만 제작했습니다. 이후 0.1.3에서 승인된 아이콘을 적용했습니다.
- 제목 필터, 예약, 알림, 백업 기능은 동일합니다.

## 0.1.1 변경 사항

- 공고 선정 기준을 제목의 **‘역사’ 포함 여부 하나**로 단순화했습니다.
- 본문 요청, 첨부 다운로드, 문서 내용 분석을 자동 수집 경로에서 제거했습니다.
- ‘확인 필요’ 탭을 없앴습니다. 제목이 맞는 공고는 일반 목록에 표시합니다.
- 기존 저장 공고와 가져온 백업에도 새 기준을 적용합니다. 관심·읽음·게시판·예약 설정은 보존합니다.
- 제목이 바뀌어 ‘역사’가 빠지면 이전에 수집한 공고도 목록에서 제외합니다.
- 이전에 알린 공고는 데이터 전환만으로 다시 알리지 않습니다.
- PDF 처리 의존성을 제거해 설치 파일과 처리 부담을 줄였습니다.

제목이 ‘한국사’나 ‘세계사’만으로 되어 있으면 현재의 문자 그대로인 ‘역사’ 조건에는 포함되지 않습니다. 반대로 제목에 ‘역사’가 있으면 시간강사나 다른 형태의 채용도 표시됩니다. **학교급·기간제 여부·지원 자격은 원문에서 직접 확인하는 방식**입니다.

## 기능

- 역사 제목 공고 / 관심 공고, 학교·지역·공고명 검색
- 게시판 추가·수정·삭제·일시중지
- ‘지금 확인’, 한국 시간 정오 12시·오후 6시 자동 확인 (시각 변경 가능)

- 목록에 나온 접수 마감 표시. 목록에 마감이 없으면 원문 확인으로 표시
- JSON 백업·복원, 진단 내용 복사, 진단용 게시판 HTML 저장
- 공고·설정은 기기에 보관. AI·유료 API·운영 서버·텔레그램 불필요

## 업데이트

0.1.1 → 0.1.2는 같은 고정 서명으로 덮어 설치할 수 있습니다.

0.1.0의 임시 서명키 캐시 경로가 실제 생성 경로와 달라 키가 남지 않았습니다. 따라서 **0.1.0에서 0.1.1로는 덮어 설치할 수 없습니다.**

1. 기존 앱에 남길 기록이 있으면 **설정 → 백업 파일 저장**을 먼저 실행합니다.
2. 기존 앱을 삭제하고 새 APK를 설치합니다.
3. **설정 → 백업 가져오기**로 게시판·관심·읽음 기록을 복원합니다. 알림 권한과 자동 확인 시각은 다시 확인하세요.
4. ‘지금 확인’으로 새 목록을 가져옵니다.

0.1.1부터는 별도로 보관하는 고정 개인 서명키로 제공 APK를 서명합니다. 같은 키를 사용하는 후속 업데이트는 덮어 설치할 수 있습니다.

새 기준과 관계없는 이전 공고는 화면에서 제외하지만, 원본 저장 항목과 관심·읽음 상태는 지우지 않습니다. 백업에도 기록은 남습니다.

## 설치·빌드

Android 8(API 26) 이상을 대상으로 작성했습니다. APK를 휴대폰에서 열고 필요하면 해당 브라우저/파일 앱의 설치를 허용합니다. 앱을 열고 알림 권한을 허용한 뒤 ‘지금 확인’을 누릅니다.

GitHub **Actions → Build APK**의 성공한 실행에는 **history-jobs-0.1.3-unsigned** artifact가 있습니다. 이것은 서명 전 APK와 공식 Android apksigner 도구입니다. 이 대화에서 제공하는 설치용 APK는 해당 빌드에 개인 서명을 추가한 파일입니다. 서명 전 APK는 설치용이 아닙니다.

Android Studio 또는 JDK 17 + Android SDK 35 환경:

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

결과: `app/build/outputs/apk/debug/app-debug.apk`

워크플로는 표준 Ubuntu runner를 사용합니다. 개인 저장소를 사용하면 계정의 무료 Actions 잔여 사용량 안에서 실행하세요. 앱 자체의 운영 서버는 없습니다.

서명키와 비밀번호는 공개 저장소·Actions artifact에 올리지 않습니다. 향후 APK를 서명할 때는 별도로 보관한 개인 키 파일과 설정을 사용합니다.

```sh
python3 tools/sign_apk.py --input history-jobs-0.1.3-unsigned.apk --output history-jobs-0.1.3.apk --signer apksigner.jar --credentials /개인경로/signing.json
```

`signing.json`은 같은 폴더의 `history-jobs.p12` 경로, 키 별칭과 암호를 담는 개인 설정 파일입니다. 배포 전 인증서 지문이 이전 제공 APK와 같은지 확인합니다. 키 보관본은 공개 저장소에 포함하지 않습니다.

## 검증

```sh
python3 tools/test_core.py
```

순수 Java 운영 모듈을 컴파일하고 합성 입력으로 검사합니다. 제목에만 ‘역사’가 있는 경우, 본문에만 ‘역사’가 있는 다른 과목 공고, 본문·첨부 요청이 전혀 발생하지 않는지, 이전 기록 재분류, 제목 수정에 따른 제외, 목록의 마감 추출 등을 검사합니다.

0.1.0에서 세 게시판의 실제 목록과 표본 상세 구조를 확인했습니다. 0.1.1의 설치·알림·기기 네트워크는 실기기 확인이 필요합니다. APK 생성 및 Android Lint 결과는 GitHub Actions와 `BUILD_STATUS.md`를 참고하세요.

## 제한

- WorkManager는 정확한 시각 실행을 보장하지 않습니다. 절전·강제 종료·네트워크 상황의 영향을 받습니다.
- 기기 시간대와 관계없이 Asia/Seoul 기준입니다.
- 한 번에 최대 20페이지, 약 35초의 목록 확인 범위를 둡니다. 진행 중인 요청은 timeout까지 더 걸릴 수 있습니다. 한도를 넘으면 부분 확인으로 표시합니다.
- 제목에 과목을 쓰지 않은 공고는 놓칠 수 있습니다. 본문이나 첨부를 통한 보완 검색은 하지 않습니다.
- 일반 게시판은 시험 지원입니다. 로그인·CAPTCHA·다른 게시판 구조는 어댑터 수정이 필요할 수 있습니다.
- 동경한국학교는 간헐적으로 사용제약 안내를 반환한 이력이 있습니다. 앱에서는 오류로 표시합니다.
- 목록에 마감 시각이 없으면 날짜 끝을 숨김 기준으로 사용하고 ‘시각은 원문 확인’으로 표시합니다.
- URL/공고 ID 기준 중복을 막습니다. 서로 다른 URL의 의미상 중복은 합치지 않습니다.
- 공고가 목록에서 사라졌다고 저장 기록을 즉시 삭제하지 않습니다.
- 백업은 공고·게시판·관심 상태를 포함합니다. 알림·확인 시각은 해당 기기의 설정에 남습니다.

## 코드

주요 경로: `app/src/main/java/kr/personal/historyjobs/`

| 파일 | 역할 |
| --- | --- |
| `core/Classifier.java` | 제목 포함 조건·기존 공고 재분류·목록 날짜 해석 |
| `core/Collector.java` | 목록 페이지만 수집, 제목에 맞는 항목 생성 |
| `core/BoardParser.java` | 서울·경기·일반 게시판 링크와 제목 해석 |
| `core/TokyoBoard.java` / `core/ArrayLiteral.java` | 동경학교 구형 목록 데이터 해석. 스크립트 실행 없음 |
| `Store.java` | 기기 내 저장, 구버전 전환, 백업 |
| `SyncEngine.java` / `CheckWorker.java` | 수집 실행, 알림, 예약 |
| `MainActivity.java` | 공고·게시판·설정 화면 |

이전 본문·한글 문서 읽기 유틸리티 일부는 코드와 회귀 검사에 남아 있지만 자동 수집에는 사용하지 않습니다.
